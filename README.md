# agent-utils

A collection of reusable agent skills and utilities.
Skills follow the Anthropic Agent Skills standard and can
be used with Claude Code, [Claude.ai](https://claude.ai), or the Claude API.

## Structure
- skills/infrastructure/ — system and server setup skills

## Contributing
PRs welcome. Each skill must be a directory containing a
SKILL.md file following the [Anthropic Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) format.
